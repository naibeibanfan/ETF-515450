# ETF-515450 · 标普红利低波50 全收益年线结构

单页可视化：价格相对 **250 日年线** 的上下位置、偏移极值、最大套牢时长。

- 数据：南方红利低波50ETF（515450）**累计净值**（全收益代理）
- 更新：GitHub Actions 每个交易日 22:15（UTC+8）自动刷新 `data.json`
- 页面：移动端适配，打开 URL 即为最新数据

## 本地预览

```powershell
# 生成/刷新数据
python scripts/fetch_update.py

# 起本地服务
python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/
```

## 部署

推送到 GitHub 后开启 Pages（Source: GitHub Actions）。  
网页会请求同目录的 `data.json`，因此只需更新数据文件，无需改页面。

## 口径

1. 年线 = 250 个交易日简单均线  
2. 连续年线上/下 = 收盘相对年线的上下切段（过滤交易日 < 5 且 |偏离| < 2% 的短噪声）  
3. 最大套牢 = 自阶段高点回落至再创新高之间的持续时间  

仅供历史结构观察，不构成投资建议。
